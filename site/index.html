Start with
a Rust toolchain.

Clone the repository and launch the console with Cargo. Running R-ust does not require an R installation.

The console keeps variables between commands and accepts multiline input. Use q() or Ctrl-D to exit. --no-save skips the default save prompt.

Install Rust

Build and launch

git clone https://github.com/adamrsophie/R-ust.git
cd R-ust
cargo run --release -p r_ust_cli -- --quiet --no-save

Evaluate an expression

cargo run -q -p r_ust_cli -- -e 'sum(1:5)'

Run a script

cargo run -q -p r_ust_cli --bin Rscript -- script.R

A clear view
of compatibility.

R 4.6.0 is the target. Language coverage and numerical behavior remain incomplete. Check the current limitations before relying on results.
